# ISO 27001:2022 ISMS Implementation & Compliance Readiness Assessment

## Project
A fictional GRC portfolio project for **FinSecure Technologies** demonstrating a risk-based approach to establishing an ISO/IEC 27001:2022-aligned ISMS.

## Skills demonstrated
- ISMS scoping
- Asset inventory
- Information-security risk assessment
- Risk register and risk treatment
- ISO 27001 Annex A control mapping
- Statement of Applicability (SoA)
- Policy development
- Control evidence review
- Internal audit testing
- Gap assessment
- Corrective action / remediation tracking
- GRC documentation

## Important
This is a simulated portfolio project. No real company systems, credentials, or confidential information were accessed. It does not claim ISO 27001 certification.

## Structure
- `01_ISMS_Scope` — ISMS scope
- `02_Asset_Management` — asset inventory
- `03_Risk_Assessment` — risk register and scoring
- `04_ISO_Controls` — Statement of Applicability
- `05_Security_Policies` — sample policies
- `06_Control_Evidence` — evidence/control matrix
- `07_Internal_Audit` — audit checklist
- `08_Gap_Assessment` — gaps and recommendations
- `09_Remediation` — corrective action plan
- `10_Final_Report` — management report
